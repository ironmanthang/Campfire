### Step 3: Posting Protocol & Avoiding Deletions/Bans (How to Post)

1. **Follow Subreddit Rules Strictly:**
   * Many subreddits restrict self-promotion. Check if the sub has a `Self-Promotion Sunday` thread or requires a `Showcase` / `Made this` post flair.
   * On `r/SelfHosted` and `r/Privacy`, emphasize that Campfire is non-commercial / free local app.
2. **Never Post a Raw Link:**
   * Subreddits and Facebook algorithms penalize post-and-run link spam.
   * Always write a rich, text-first post sharing your personal story or solving a problem, then include links naturally at the bottom.
3. **The "Dual-CTA" Funnel Strategy:**
   * **Hook:** Give readers instant access via the **Web PWA** (`https://app-campfire.pages.dev/`) so they can test the UI in 1 click without installing.
   * **Convert:** Guide Windows desktop users to the **Microsoft Store** (`https://apps.microsoft.com/...`) for offline usage and background GDrive backup.

---

### Step 4: Post-Launch Engagement & Lead Conversion (The Golden First 2 Hours)

* **The 2-Hour Golden Rule:** When you submit a post on Reddit or Facebook, stay active for the first 2 hours. Reply to **EVERY SINGLE COMMENT**.
* **Handling Questions:**
  * *Q: "Is my data uploaded to your server?"* -> A: "Zero data is sent to any server hosted by me. All data lives on your device or your personal Google Drive."
  * *Q: "Can I use my own API key / local AI?"* -> A: Yes! Highlight BYO API key and Ollama / local LLM support.
* **Collect Feedback:** End replies by asking: *"What feature would make Campfire your daily driver journal?"* This converts casual viewers into active testers and collaborators.
